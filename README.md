# Sheet Magnet Connector

Foundry VTT module that connects to the [Sheet Magnet](https://github.com/RebelliousSmile/sheetmagnet) PWA for exporting character sheets to PDF, PNG, and print formats.

## Installation

In Foundry VTT (or Forge VTT), go to **Add-on Modules → Install Module** and paste this manifest URL:

```
https://raw.githubusercontent.com/RebelliousSmile/sheet-magnet-connector/main/module.json
```

## Usage

1. Enable the module in your world
2. Open the **Actors Directory** — a **Sheet Magnet** button appears in the header
3. Click it to get your connection URL and token
4. Enter them in the Sheet Magnet PWA
